Section 1: Prerequisites

  • AI Gateway running: Create a Konnect personal access token. Export token:

    export KONNECT_TOKEN='YOUR_KONNECT_PAT'

  • Run quickstart:

    curl -Ls https://get.konghq.com/ai | bash -s -- -k $KONNECT_TOKEN

  • Export resulting vars:

    export AI_GATEWAY_ID=
export KONNECT_TOKEN=$KONNECT_TOKEN
export KONNECT_CONTROL_PLANE_NAME=ai-quickstart
export KONNECT_CONTROL_PLANE_URL=https://us.api.konghq.com
export KONNECT_PROXY_URL='http://localhost:8000'

  • kongctl v1.16.0+: Install and verify:

    kongctl version

  • OpenAI: Get an API key and export:

    export OPENAI_API_KEY='YOUR_OPENAI_API_KEY'

Section 2: Create an AI Model Provider entity

  • Create provider to define connection. Set auth header:

    export OPENAI_AUTH_HEADER="Bearer $OPENAI_API_KEY"

  • Apply config:

    kongctl apply -f - --auto-approve --pat "$KONNECT_TOKEN" << 'EOF'
ai_gateway_model_providers:
  - ref: generic-openai
    ai_gateway: !lookup {id: !env AI_GATEWAY_ID}
    name: generic-openai
    display_name: "generic-openai"
    type: openai
    config:
      auth:
        type: basic
        headers:
          - name: Authorization
            value: !secret {source: !env OPENAI_AUTH_HEADER}
EOF

Section 3: Create an AI Model entity

  • Declare upstream models and routing:

    kongctl apply -f - --auto-approve --pat "$KONNECT_TOKEN" << 'EOF'
ai_gateway_models:
  - ref: my-gpt-4o
    ai_gateway: !lookup {id: !env AI_GATEWAY_ID}
    name: my-gpt-4o
    display_name: "my-gpt-4o"
    type: model
    formats:
      - type: openai
    config:
      route:
        paths:
          - /v1
        model:
          body_param: model
          values:
            - my-gpt-4o
    targets:
      - name: gpt-4o
        provider: generic-openai
        config:
          type: openai
    policies: []
    capabilities:
      - generate
EOF

Section 4: Validate

  • Send a chat request to verify setup:

    curl -X POST "$KONNECT_PROXY_URL/v1/chat/completions" \
  --no-progress-meter --fail-with-body \
  -H "Accept: application/json"\
  -H "Content-Type: application/json"\
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  --json '{
    "messages": [
      {
        "role": "user",
        "content": "Say this is a test!"
      }
    ],
    "model": "my-gpt-4o"
  }'
