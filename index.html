Start with AI Gateway 2.0

Prerequisites

  • A running instance of Kong Gateway 3.8.x or later.
  • The kongctl CLI tool installed and configured.
  • An active API key from an LLM provider (e.g., OpenAI).

1. Create AI Model Provider

First, define your chosen AI provider and securely store your authentication credentials. Create a file named provider.yaml:

name: openai-provider
type: ai-model-provider
provider: openai
auth_credentials:
  auth_header_value: Bearer <YOUR_OPENAI_API_KEY>

Apply the configuration using kongctl:

kongctl apply -f provider.yaml

2. Create AI Model

Next, define the specific LLM model you wish to use and link it to the provider created above. Create a file named model.yaml:

name: openai-gpt4o
type: ai-model
provider_name: openai-provider
model: gpt-4o

Apply the configuration:

kongctl apply -f model.yaml

3. Validate via Curl

Test your newly configured AI Gateway by sending a standard chat completion request to your Kong Gateway endpoint:

curl -X POST http://localhost:8000/openai-gpt4o/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {
        "role": "user",
        "content": "What is Kong API Gateway?"
      }
    ]
  }'

Konnect UI: Core Setup

Detailed step-by-step guide to setting up AI Gateway in Konnect.

  1. Step 1: Log in to cloud.konghq.com.
  2. Step 2: Navigate to AI Gateway in the left menu and click New AI Gateway to create a control plane.
  3. Step 3: Go to AI Model Providers, click New Provider, select a provider (e.g., OpenAI), and securely input your API key.
  4. Step 4: Go to AI Models, click New Model, link it to your provider, and specify the upstream model (e.g., gpt-4o).
  5. Step 5: Copy the quickstart script provided in the UI to deploy your local data plane node.

Konnect UI: AI Rate Limiting

Control AI costs by limiting traffic based on LLM token consumption rather than standard HTTP requests.

  • Navigate to the Plugins tab of your AI Gateway or specific AI Route.
  • Click Add Plugin and search for AI Rate Limiting Advanced.
  • Set the Limit Type to Tokens (to limit by LLM usage rather than HTTP requests).
  • Configure the Config.Limit (e.g., 5000 tokens) and Config.Window Size (e.g., 60 seconds).
  • Apply the limit by Consumer, Consumer Group, or IP address to ensure fair usage and control costs. Save the plugin.

Konnect UI: Semantic Prompt Guard

Protect your LLMs by evaluating the actual meaning and intent of user prompts, moving beyond rigid regex keywords.

  • In the Plugins section, add the AI Semantic Prompt Guard plugin.
  • Note: Semantic policies require configuring an Embeddings provider (e.g., text-embedding-3-small) in the plugin settings to convert prompts to vectors.
  • Scroll to Deny Topics or Allow Topics.
  • Instead of strict regex, enter natural language intents. For example, add "Financial advice", "Hate speech", or "Competitor mentions" to the Deny list.
  • Save the configuration. Kong will now evaluate the meaning of the prompt and block it if it semantically matches the denied topics.

Konnect UI: Semantic Caching

Dramatically reduce latency and API costs by caching responses for questions that mean the same thing, even if phrased differently.

  • Add the AI Semantic Caching plugin to your model or route.
  • Configure your Embeddings model credentials within the plugin.
  • Set the Distance Threshold (e.g., 0.15). This defines how similar a new prompt must be to a cached prompt to trigger a cache hit (lower means more exact).
  • Choose your cache storage backend (e.g., Redis or in-memory).
  • Save the plugin. This will dramatically reduce latency and LLM costs by serving cached responses for similarly phrased questions.

Konnect UI: Semantic Routing

Dynamically steer traffic to the most appropriate AI model based on the user's intent.

  • Add the AI Semantic Routing plugin.
  • Set up the embeddings configuration.
  • Define intent-based routing rules. For example, create a rule where the intent "Create an image or picture" routes to your DALL-E AI Model, and the intent "Write code" routes to an Anthropic Claude model.
  • Save the plugin to enable dynamic, intent-based traffic steering across multiple AI models.

Konnect UI: Prompt Decorator

Enforce systemic instructions globally without relying on client-side prompt engineering.

  • Add the AI Prompt Decorator plugin.
  • Define a rule to inject a specific prompt into the user's messages array.
  • Set the Role to system.
  • Set the Content (e.g., "You are a helpful assistant. Always reply in French and format your output in Markdown.").
  • Choose whether to Prepend or Append this message to the user's request array. Save the plugin to enforce systemic instructions globally.

Konnect UI: Prompt Template

Simplify client requests and standardize LLM inputs using server-side templates.

  • Add the AI Prompt Template plugin.
  • Click Add Template and define a name (e.g., code-generator).
  • In the template body, write a JSON structure using Mustache variables. Example: [{"role": "user", "content": "Write a {{language}} script to {{task}}"}].
  • Toggle Allow Untemplated Requests to false if you want to block raw, unstructured prompts.
  • Save the plugin. Clients can now send lightweight requests like {"language": "Python", "task": "reverse a string"} and Kong will construct the full LLM prompt.
